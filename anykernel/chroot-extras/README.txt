chroot-extras — files for the Kali/NetHunter chroot (not the Android system)
===========================================================================

hwdb.bin
--------
A precompiled udev hardware database (/etc/udev/hwdb.bin), generated by the
CI build on a modern-kernel runner and published as a SEPARATE release asset
(it is intentionally NOT bundled in the flashable AnyKernel zip and NOT
installed by the flasher).

Why it exists:
  Modern usbutils `lsusb` looks up vendor/product names through libudev's
  hwdb (udev_hwdb_new()), NOT the text usb.ids file. On the Nexus 6P the
  Kali chroot ships systemd/udev 260, which is far newer than this 3.10
  kernel, so `systemd-hwdb update` cannot read its hwdb.d source dirs on the
  device ("Protocol driver not attached") and never builds hwdb.bin. Without
  that file `lsusb` aborts with "unable to initialize usb spec".

  libudev only mmaps hwdb.bin at runtime (plain file I/O that works fine on
  3.10), so dropping a prebuilt file in place fixes lsusb completely.

Manual install (inside the Kali/NetHunter chroot, as root)
----------------------------------------------------------
Download the hwdb.bin asset from the build's GitHub Release straight into
the chroot's udev dir:

    wget -O /etc/udev/hwdb.bin \
      https://github.com/9hm2/android_kernel_huawei_angler/releases/download/<TAG>/hwdb.bin

  or:

    curl -L -o /etc/udev/hwdb.bin \
      https://github.com/9hm2/android_kernel_huawei_angler/releases/download/<TAG>/hwdb.bin

Replace <TAG> with the release tag (e.g. build-YYYYMMDD-<sha>). Then:

    lsusb        # now lists devices with vendor/product names

No-hwdb fallback
----------------
If you cannot fetch the file, enumerate USB straight from /sys (no hwdb,
no names but full IDs):

    usb-devices                       # ships with usbutils, reads /sys
    for d in /sys/bus/usb/devices/*/; do
      [ -r "$d/idVendor" ] || continue
      printf 'Bus %03d Device %03d: ID %s:%s %s %s\n' \
        "$(cat "$d/busnum")" "$(cat "$d/devnum")" \
        "$(cat "$d/idVendor")" "$(cat "$d/idProduct")" \
        "$(cat "$d/manufacturer" 2>/dev/null)" "$(cat "$d/product" 2>/dev/null)"
    done
